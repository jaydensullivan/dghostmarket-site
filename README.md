# dghostmarket.com

Сайт-визитка DGhostMarket — маркетплейса скинов CS2 в Telegram.

Статическая страница без сборки: `index.html`, картинки рядом. Публикуется через GitHub Pages
(Settings → Pages → Deploy from a branch → `main` / `(root)`), домен задан в файле `CNAME`.

Документы (оферты, политика конфиденциальности) не дублируются здесь — сайт ссылается на
действующие редакции, которые отдаёт бот: `https://api.dghostmarket.com/legal`.
