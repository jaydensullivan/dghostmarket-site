# dghostmarket.uz

Сайт-визитка DGhostMarket — маркетплейса скинов CS2 в Telegram.

Статический сайт. Публикуется через GitHub Pages (Settings → Pages → Deploy from a branch →
`main` / `(root)`), домен задан в файле `CNAME`.

Страницы собираются скриптом `tools/build.py` (только стандартная библиотека Python):

- `src/index.html` — шаблон лендинга, русский текст прямо в разметке (`data-i18n`);
- `i18n.json` — узбекский и английский переводы (и заголовки/описания для поиска);
- на выходе: `index.html`, `uz/index.html`, `en/index.html` — лендинг на трёх языках;
  `skins/`, `uz/skins/`, `en/skins/` — цены из живых лотов маркета (открытый API бота);
  `sitemap.xml`, `robots.txt`.

Править нужно шаблон и `i18n.json`, а не готовые `index.html` — их перезапишет сборка.
Сборка запускается сама (`.github/workflows/build.yml`) раз в сутки и после правок шаблона,
переводов или сборщика; вручную — Actions → «Сайт: сборка страниц» → Run workflow.

Документы (оферты, политика конфиденциальности) не дублируются здесь — сайт ссылается на
действующие редакции, которые отдаёт бот: `https://api.dghostmarket.uz/legal`.
