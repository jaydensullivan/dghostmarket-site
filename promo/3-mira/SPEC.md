# SPEC — DGhost «Три мира» (15 с, RU + UZ)

GOAL:    зритель понял, что в одном боте @dghostmarketbot три раздела — Скины CS2, Подарки Telegram, Пополнения — и открыл бота.
OUTPUT:  HyperFrames, 1080 x 1920, 30 fps; две версии из одного проекта: переменная `lang` = ru | uz.
TIME:    15 s = 450 frames; 120 BPM, beat 15 frames.
LOOK:    бренд мини-аппа: фон #08070D; цвет раздела — Скины #7c3aed→#9333ea, Подарки #c026d3→#ec4899,
         Пополнения #4f46e5→#3b82f6; акцент бренда #7B2CFF→#FF2BD6 только на «один бот» и кнопке бота.
         Orbitron 900 — только латиница бренда (DGhost, 01 / MARKETPLACE); Inter 900 — заголовки (кириллица и узбекский), 72–96 px;
         Inter 700 36 px — подписи. Экраны — настоящие снимки app.dghostmarket.uz (assets/screens), телефон 600 px, скругление 56 px.
COPY:    дословно из словарей мини-аппа (app-i18n.js / app-i18n-uz.js), кроме хука «Три мира — один бот».
SHOTS (9:16; 4:5 — то же, другая раскладка):

  skins  2.0–5.6  01 / MARKETPLACE · «Скины CS2 за сумы»; блик по Covert-лоту (dgSheen); нажатие;
